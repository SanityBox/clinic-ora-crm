# תוכנית · חיזוק ממשק הסוכן (שאלות 4–5)

**בעיות (מבדיקות הסוכן ומסקירה עצמית עם סוכן AI):**
1. בבדיקה הסוכן שלח את מספר הוואטסאפ של הקליניקה כטלפון של הלקוחה, ונוצרה לקוחה כפולה.
2. ניסיון חוזר של n8n (`retryOnFail`) על POST עלול לפתוח שתי קריאות זהות.
3. בקשת נציגה נפתחת בעדיפות רגילה, ואין התראה אקטיבית לצוות ("לא אופציונלי" בקורס).
4. "התור הבא" מחזיר שם פרטי ומטפלת, אבל PRD 10.2 קובע מינימום: תאריך, שעה וסוג טיפול.

**שינוי (migration חדש `20261010100000_agent_api_hardening.sql`, בלי לשנות migrations קיימים):**
- `agent_create_ticket(p_name, p_phone, p_description, p_request_type default null)`:
  - הטלפונים של הקליניקה (0547821390, 097745120) ← `ok:false, error:'clinic_phone'`.
  - כפילות: אותה לקוחה, מקור סוכן, אותו תיאור, ב-10 הדקות האחרונות ← מחזירים את הקריאה הקיימת עם `duplicate:true`.
  - בקשת נציגה (`p_request_type = 'בקשת נציגה'`, או תיאור שמתחיל ב-`[בקשת נציגה]`) ← עדיפות `urgent`.
- `agent_next_appointment`: מחזיר רק תאריך, יום, שעה וסוג טיפול. בלי שם פרטי ובלי מטפלת.
- n8n: מעביר את `request_type`, ומתרגם `clinic_phone` להודעה לסוכן "צריך את מספר הטלפון של הלקוחה, לא של הקליניקה".

**בדיקה (curl דרך n8n, ו-SQL):** טלפון קליניקה ← `ok:false`. אותה פנייה פעמיים ← אותו מספר קריאה. בקשת נציגה ← `priority = urgent`. התור הבא ← בלי `first_name` ובלי `therapist`. בלי מפתח ← 403.

**מחוץ לתחום כאן:** התצוגה במסך הראשי (באנר "ביקשו נציגה" ותגית "סוכן AI") נמצאת בתוכנית נפרדת.
